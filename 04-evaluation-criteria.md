# Evaluation Criteria for SeMT Wi‑Fi Project

## 1. Purpose
The selection of the system integrator is based on technical competence, financial strength, relevant experience and compliance with the tender conditions.

## 2. Typical Evaluation Structure
OCAC-style tenders generally split evaluation into:
- Pre-qualification / eligibility criteria
- Technical bid evaluation
- Commercial bid evaluation

## 3. Pre-Qualification Criteria
The bidder is usually expected to demonstrate:
- valid registration and legal identity,
- financial capacity,
- prior experience in similar network and Wi‑Fi implementation projects,
- technical manpower capability,
- support network and maintenance infrastructure,
- compliance with statutory requirements.

## 4. Technical Bid Evaluation Criteria
Typical technical evaluation areas include:
- project understanding,
- proposed architecture and design quality,
- experience in similar deployments,
- implementation plan and timeline,
- service support and SLA proposal,
- security features,
- equipment standards and certifications,
- local support capabilities.

## 5. Commercial Bid Evaluation
Commercial bid evaluation normally includes:
- itemized pricing,
- unit rates,
- optional prices if any,
- cost reasonableness and completeness,
- payment schedule,
- warranty and AMC cost assumptions.

## 6. Scoring Principle
A government RFP usually does not award purely on the lowest price. The standard model is:
- technical score first,
- then price comparison among technically qualified bidders.

This ensures the selected bidder is not only cheap but also able to deliver secure and sustainable Wi‑Fi service.

## 7. Importance to the Project
This evaluation model protects institutions from weak vendors who may quote low but fail on:
- coverage quality,
- network resiliency,
- support capability,
- service level compliance,
- security standards.
