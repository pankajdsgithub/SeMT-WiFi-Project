# Annexure List
## SeMT Wi‑Fi Submission Package

## Annexure A: Bidder Profile
- organisation name,
- address,
- contact details,
- registration details,
- authorised signatory.

## Annexure B: Company Registration and Statutory Documents
- GST certificate,
- PAN,
- company registration certificate,
- MSME / eligibility certificates, if applicable.

## Annexure C: Financial Capacity
- audited financial statements,
- turnover certificate,
- bank solvency / financial support declaration.

## Annexure D: Similar Project Experience
- project references,
- client certificates,
- implementation details,
- period of execution.

## Annexure E: Technical Compliance Matrix
- response to Wi‑Fi technical specifications,
- product datasheets,
- OEM declaration,
- architecture compliance checklist.

## Annexure F: Project Implementation Schedule
- milestone chart,
- manpower deployment plan,
- site mobilisation schedule,
- commissioning timeline.

## Annexure G: BOQ and Commercial Schedule
- item-wise pricing,
- total bid value,
- optional items,
- GST / taxes schedule.

## Annexure H: Warranty and Support SLA
- warranty period,
- support model,
- response time,
- service escalation matrix,
- spares support plan.

## Annexure I: Bidder Declaration Forms
- anti-corruption declaration,
- no-blacklisting declaration,
- acceptance of tender terms,
- conflict of interest declaration.

## Annexure J: Training and Handover Plan
- training schedule,
- administration training plan,
- as-built documentation list,
- handover checklist.

## Annexure K: Security and Compliance Declaration
- cybersecurity compliance,
- data protection measures,
- access control policy,
- secure network architecture statement.

## Annexure L: Approved Drawing and Design Summary
- network topology,
- AP locations,
- switch locations,
- control room connectivity,
- architecture diagrams.
