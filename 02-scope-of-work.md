# Scope of Work
## SeMT Wi‑Fi for State Public Universities

## 1. Purpose
This scope defines the functional and technical responsibilities expected from the selected System Integrator for implementing campus Wi‑Fi infrastructure for the participating universities.

## 2. Scope Elements
### 2.1 Site Survey and Network Assessment
- assess campus topology,
- identify user density and coverage zones,
- examine existing network and power availability,
- map building layout and coverage needs,
- identify constraints such as interference, glass, concrete structures and distance.

### 2.2 Network Design
- prepare detailed wireless design,
- propose access point layout and channel strategy,
- define core/distribution access layer architecture,
- include redundancy and fault tolerance,
- design for scalability and future expansion.

### 2.3 Supply of Equipment
- access points,
- controllers or cloud management systems,
- switches and uplinks,
- controllers / aggregation devices,
- outdoor units where required,
- power supply, mounting accessories, network elements,
- licenses and support tools.

### 2.4 Implementation and Integration
- installation of hardware,
- cable routing and termination,
- configuration and integration with core network,
- commissioning of access points,
- validation of connectivity and signal strength,
- integration with existing infrastructure where applicable.

### 2.5 Security Implementation
- role-based access control,
- guest access segmentation,
- secure authentication and authorization,
- firewall and segmentation policy,
- centralized logging and monitoring,
- device policy and access validation.

### 2.6 Testing and Commissioning
- RF validation,
- throughput and coverage tests,
- access validation,
- authentication and policy checks,
- uptime verification,
- user acceptance testing.

### 2.7 Documentation and Training
- as-built drawings,
- configuration reports,
- user manuals,
- training for administrators and support personnel,
- operational handover package.

### 2.8 Operations and Maintenance
- preventive maintenance,
- fault response and support,
- warranty support,
- SLA-driven support for the covered campus network.

## 3. Exclusions
Any work outside the approved scope such as major civil works, external power upgrades, or additional network capex not included in the tender shall be treated as extra work subject to prior approval.

## 4. Deliverables
The system integrator shall provide:
- installed and commissioned Wi‑Fi network,
- complete documentation,
- operational support during the warranty period,
- user training,
- final acceptance certificate and handover notes.
