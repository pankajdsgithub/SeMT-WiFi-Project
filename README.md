## Key Insight from the Source RFP
The OCAC tender is not a generic project brief. It is a formal procurement package with these major components:
1. Fact Sheet / project summary
2. Proposal and background information
3. Scope of work
4. Instructions to bidders
5. Eligibility and prequalification
6. Technical bid evaluation criteria
7. Commercial bid evaluation
8. Appointment of vendor and project deliverables
9. Contract terms, warranties, penalties, and SLA
10. Annexures and bid forms
